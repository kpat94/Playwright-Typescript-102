# Playwright + TypeScript — Practice Project

Practice project that demonstrates how to use Playwright with TypeScript for automation testing.

Covers:
- API tests
- Snapshot testing
- Visual regression

Explains how to mock API requests and responses (used in conjunction with network interception).

## Steps to run the tests

- Launch the tests in UI mode (e.g. `npx playwright test --ui`).
- Use the VS Code test runner.

## Folder structure

```
tests/        # Contains the test scripts
screenshots/  # Saved screenshots taken during the test
fixtures/     # Fixture classes to set up the tests
pages/        # Page classes that contain locators and helper methods
```
