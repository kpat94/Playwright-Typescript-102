Practise project that demonstrates how to use Playwright with Typescript for automation testing;

Covers API tests, snapshot testing and visual regression; 

Explains how to mock API requests and responses(Used in conjunction with network interception.)

##Steps to run the tests:
-Launch the tests in the UI mode.
-Use the Vscode test runner.

##Folder structure:
###tests\
-Contains the test scripts.
###screenshots\
-save screenshots taken during the test.
###fixtures\
-Fixture classes to set up the tests.
###pages\
-Page classes that contain locators and helper methods.
